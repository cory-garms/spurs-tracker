Fonts used to draw the link-preview images (viz/share_images.py). The web pages
load the same families from Google Fonts.

All are from github.com/google/fonts and licensed under the SIL Open Font
License 1.1, which permits bundling and redistribution (OFL-Rye.txt is one copy
of the license text; the terms are identical for each family):

- Bowlby One (BowlbyOne-Regular.ttf)
- Rye (Rye-Regular.ttf)
- VT323 (VT323-Regular.ttf)
- Teko (Teko[wght].ttf, variable weight)
- Courier Prime (CourierPrime-Bold.ttf)
